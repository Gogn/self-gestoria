# sources/ — оригиналы первоисточников

Слой «сырых источников» из паттерна LLM-Wiki. `knowledge/` — пересказ правил своими
словами; здесь — **дословный текст**, на который этот пересказ опирается. Если
утверждение в `knowledge/` с тегом `[норма]` нельзя найти здесь или по ссылке из
`knowledge/sources-primarias.md`, это не норма.

## Правила

- 🔴 **Файлы здесь вручную не правятся.** Текст берёт `sources/fetch.py` по
  `sources/manifest.json`: из API консолидированного законодательства BOE и со
  страниц AEAT. Модель его не пересказывает и не переписывает — иначе слой теряет
  смысл.
- Каждый файл несёт шапку: источник, дата снятия, по каждому блоку — с какой даты
  действует эта редакция и каким актом внесена. Для страниц AEAT — дата обновления
  страницы.
- Обновить = перезапустить скрипт. Скрипт пишет `ИЗМЕНИЛСЯ`, если текст отличается
  от прежнего, — тогда `git diff sources/` покажет, что именно поменялось в норме, и
  это повод перепроверить зависящие страницы `knowledge/`.
- Здесь только публичные тексты. Личные документы — в `my-data/`.

## Как добавить источник

Это часть операции *ingest* — порядок в `/ingest`.

1. BOE: найти идентификатор акта (`BOE-A-…`) и блок статьи. Блоки перечислены в
   оглавлении: `https://www.boe.es/datosabiertos/api/legislacion-consolidada/id/<BOE-A-…>/texto/indice`.
   Статья N обычно — блок `aN`, но не всегда (в PGC — `A11` и т.п.): сверять по оглавлению.
2. Добавить блок в существующую запись манифеста или новую запись.
3. `python3 -I sources/fetch.py <файл>` и прочитать результат.
4. Добавить якорь в `knowledge/sources-primarias.md`.

## Права

- Тексты BOE — нормативные акты, не объект авторского права (Ley de Propiedad
  Intelectual, art. 13).
- Тексты AEAT — повторное использование разрешено с указанием источника и даты
  обновления, без искажения содержания (Sede → Aviso legal → *Utilización de la
  información contenida en la web*). Шапка файла выполняет эти условия.
- Страницы ЕЦБ сюда не копируются — только ссылки в `knowledge/`.
