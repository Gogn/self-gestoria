# Чек-лист квартальной подачи

Скопируйте в `my-data/<ГОД>-Q<N>/checklist.md` и отмечайте по ходу.

## A. Сбор данных

- [ ] Все счета за квартал собраны (по дате счёта, не по дате оплаты)
- [ ] Все расходы собраны, у каждого определено: есть ли испанский НДС + есть ли полная *factura*
- [ ] **Cuota de autónomos за квартал учтена** ← самый частый пропуск
- [ ] Накопительные величины взяты из *justificantes* предыдущих деклараций, не по памяти
- [ ] Накопленный НДС-кредит (casilla 110) выписан из предыдущей модели 303

## B. Расчёт — модель 130

- [ ] casilla 01 = доходы **с 1 января**, не за квартал
- [ ] casilla 02 = расходы **с 1 января**, включая cuota de autónomos
- [ ] casilla 03 = 01 − 02
- [ ] casilla 04 = 20 % × 03
- [ ] casilla 05 = сумма casilla 19 из уже поданных 130 этого года (в Q1 — пусто)
- [ ] casilla 06 = retenciones (0, если клиентов-резидентов нет)
- [ ] casilla 19 — итог; если ≤ 0, декларация *negativa*, но подать всё равно надо

## C. Расчёт — модель 303

- [ ] Проверено по decision tree, начисляется ли клиентам испанский НДС
- [ ] Блок IVA devengado заполнен согласно профилю (для клиентов вне ЕС B2B — пусто)
- [ ] casillas 28/29 = только расходы с испанским НДС и полной *factura*
- [ ] casilla 110 = накопленный кредит перенесён
- [ ] **Справочная графа оборота заполнена** (для клиентов вне ЕС — доход за квартал)
- [ ] Нумерация casillas сверена в PRE303 или в самой форме

## D. Сверка — обязательно

- [ ] **Доход в 130 согласуется с оборотом в 303**

  Способ сверки: `casilla 01` модели 130 за текущий квартал минус `casilla 01`
  модели 130 за предыдущий квартал = оборот, заявленный в модели 303 за текущий квартал.

  Для Q1: `casilla 01` (130) = оборот в 303 напрямую.

  Расхождение → ищите причину до подачи. Это главный триггер *requerimiento*.

- [ ] Расходы в 130 **больше или равны** базе расходов в 303 (не все расходы несут НДС) —
      если наоборот, где-то ошибка
- [ ] Арифметика пересчитана калькулятором, не в голове
- [ ] Суммы округлены до 2 знаков

## E. Подача

- [ ] Соблюдён срок (при домициляции — более ранний дедлайн, см. `deadlines.md`)
- [ ] Способ оплаты 130 выбран сознательно (NRC/карта надёжнее домициляции)
- [ ] Модель 303 подана
- [ ] Модель 130 подана
- [ ] **Оба *justificante* (PDF) скачаны** в `my-data/<ГОД>-Q<N>/`
- [ ] Если платили не домициляцией — платёж подтверждён (NRC получен)
- [ ] Если домициляцией — напоминание проверить баланс счёта в день списания

## F. После подачи

- [ ] *Mis notificaciones* проверены на новые уведомления
- [ ] Значения для следующего квартала выписаны: доходы/расходы YTD, уплачено по 130,
      новый остаток НДС-кредита
- [ ] Очередной платёж по рассрочке оплачен, если есть
      (только через *Aplazamientos → Contestar requerimientos y otras gestiones*)
- [ ] Даты следующего квартала и следующего платежа рассрочки в календаре
- [ ] Настроены автоматические напоминания о сроках — подписка на календарь
      [radarfiscal.es](https://radarfiscal.es) и/или бот
      [@Autonomo_Help_Bot](https://t.me/Autonomo_Help_Bot) (см. `knowledge/deadlines.md`)
