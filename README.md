# Self Gestoría — самостоятельная подача налогов как autónomo в Испании

База знаний + рабочие шаблоны для того, чтобы считать и подавать квартальные и годовые
налоговые декларации в Испании самому, без гестора — с помощью ИИ-агента как ассистента.

> ⚠️ **Это не профессиональная налоговая консультация.** Материалы носят справочный
> характер, могут устареть и не учитывают вашу конкретную ситуацию. Ответственность за
> содержание поданных деклараций несёт налогоплательщик. Спорные моменты — к
> лицензированному gestor / asesor fiscal или напрямую в AEAT.

## Как пользоваться

1. Установите [Claude Code](https://claude.com/claude-code) (или другой ИИ-агент, читающий папку).
2. Склонируйте репозиторий и откройте папку агентом:
   ```bash
   git clone <URL> self-gestoria && cd self-gestoria && claude
   ```
3. Скажите: **«Старт»**.

Агент прочитает [CLAUDE.md](CLAUDE.md), объяснит процесс, проверит, есть ли у вас доступ
к Sede Electrónica, и скажет, **какие данные от вас нужны**. Расчётов на этом шаге не
будет — сначала сбор.

Дальше можно говорить обычными словами: «посчитай декларации за квартал», «проверь перед
подачей», «загрузи мои прошлые декларации».

### Если вы уже подавали декларации — начните с импорта

👉 **Самый быстрый и надёжный путь.** Скачайте из Sede Electrónica:

- *Consultar declaraciones presentadas* → PDF всех деклараций за 2 года (лучше 4);
- *Mis datos censales* → PDF или скриншот.

Положите в `my-data/history/` и скажите: **«загрузи мои прошлые декларации»**.

Агент восстановит профиль из того, что AEAT уже принял: режим налогообложения, коды
IAE, набор обязательных моделей, логику НДС — и извлечёт **переносимые величины**
(доход и расходы с начала года, уплаченное по модели 130, накопленный НДС-кредит).
Именно в этих цифрах чаще всего ошибаются, и взять их больше негде.

Заодно проведёт **аудит прошлых подач** — не терялась ли cuota de autónomos, переносился
ли НДС-кредит, заполнялась ли справочная графа оборота, все ли кварталы поданы.

Декларации показывают, *что было заявлено*, а не *что было правильно* — поэтому импорт
всегда включает аудит, а часть данных (полнота расходов, тип клиента, зарубежные активы)
агент всё равно спросит. Подробности:
[knowledge/import-previous-filings.md](knowledge/import-previous-filings.md).

### Если это первая подача

Агент пройдёт с вами [decision tree](knowledge/00-profile-decision-tree.md) — семь
вопросов, определяющих, какие модели вам вообще нужны. Дальше попросит цифры за квартал
и выдаст готовый лист «что вписать в какую casilla».

## Учёт расходов — теперь ваша задача

Работая через гестора, вы просто отдавали ему расходы. При самоподаче эта роль
переходит к вам: вести книги учёта (*libros de registro*) — обязанность autónomo, а не
удобство.

Главное правило: **расходы собираются в момент траты, а не в конце квартала.** Задним
числом фактуру у поставщика часто уже не получить, а незаявленный расход стоит 20 % от
своей суммы в авансе плюс до 21 % невычтенного НДС.

Месячная рутина на 15 минут, требования к документам (*factura* против *ticket*),
структура хранения и частые ситуации — в
[knowledge/gastos-workflow.md](knowledge/gastos-workflow.md).
Что именно вычитается — в [knowledge/gastos-deducibles.md](knowledge/gastos-deducibles.md).

## Какие данные понадобятся

Полный список — в [templates/data-request.md](templates/data-request.md).
Если импортировали историю подач, профиль и накопительные величины подставятся сами —
спрашивать останется только про текущий квартал. Коротко:

- профиль: режим налогообложения, страна и тип клиентов, есть ли сотрудники / аренда;
- доходы за период: все выставленные счета (дата, сумма, клиент);
- расходы за период: сумма, есть ли испанский НДС, назначение;
- уплаченная cuota de autónomos;
- сколько уже уплачено по авансовым платежам в этом году;
- накопленный НДС-кредит из прошлых периодов.

**Персональных данных агенту для расчёта не нужно** — ни NIF, ни IBAN, ни ФИО.
Они нужны только вам в момент входа в Sede Electrónica.

## Сроки

Полный календарь, правило переноса с выходных, конкретные даты 2026–2027 и последствия
просрочки — в [knowledge/deadlines.md](knowledge/deadlines.md).

Коротко: квартальные декларации — до **20 апреля / 20 июля / 20 октября / 30 января**.
При оплате домициляцией подавать нужно на несколько дней раньше.

⚠️ Срок на выходном переносится на следующий рабочий день. Например, Q4 2026: 30 января
2027 — суббота, значит крайний срок **1 февраля 2027**.

### Напоминания и сверка сроков

Чтобы не следить за календарём вручную:

- **[radarfiscal.es](https://radarfiscal.es)** — налоговый календарь для autónomos с
  подпиской в Google Calendar / Apple Calendar / Outlook. Даты обновляются автоматически
  при изменениях у AEAT, набор моделей фильтруется под ваш профиль. Бесплатно, без
  регистрации, есть [русская версия](https://radarfiscal.es/ru/).
- **[@Autonomo_Help_Bot](https://t.me/Autonomo_Help_Bot)** — Telegram-бот для сверки
  сроков и напоминаний.

Это второй контур защиты, а не замена первоисточнику: перед подачей всё равно сверяйтесь
с *Calendario del contribuyente* AEAT, а личные требования от Hacienda видны только в
*Mis notificaciones* в Sede Electrónica.

## Структура

```
knowledge/       обезличенные правила: модели, сроки, casillas, вычеты,
                 учёт расходов, грабли
templates/       вопросники, YAML-формы данных, чек-листы
examples/        разобранные кейсы с цифрами
my-data/         ваши реальные данные — в .gitignore, наружу не уходит
  history/       justificantes прошлых деклараций + восстановленная картина
.claude/skills/  команды агента:
                   /start               точка входа: что нужно от вас
                   /import-history      восстановить профиль из прошлых деклараций
                   /collect-data        собрать данные за квартал
                   /quarterly-filing    рассчитать casillas
                   /consistency-check   сверка перед подачей
```

## Приватность

`my-data/` исключена из git. Ничего личного в остальных папках быть не должно.
Перед первым push рекомендуется поставить защиту от случайного коммита секретов:

```bash
brew install gitleaks && gitleaks git --pre-commit
```

## Актуальность

Правила меняются. Каждый файл в `knowledge/` содержит шапку `Актуально на:` и список
того, что нужно перепроверять. Известные будущие изменения — в
[knowledge/upcoming-changes.md](knowledge/upcoming-changes.md).

## Вклад

Профилей autónomo много, а покрыт пока один-два. PR с новыми профилями (испанские
клиенты, клиенты в ЕС, módulos, сотрудники, аренда) приветствуются — только без
персональных данных в примерах.

### Соглашения

| Что | Язык |
|---|---|
Содержимое файлов, документация | Русский |
**Сообщения коммитов, названия ветвей, заголовки PR** | **Только английский** |
Термины испанского налогового права | Оставлять по-испански (*factura*, *casilla*, *aplazamiento*) |

Репозиторий публичный, поэтому git-история должна читаться теми, кто русского не знает.

Формат сообщения коммита — императив в настоящем времени, подпись до ~72 символов,
без точки в конце:

```
Add modelo 349 guidance for EU clients
Fix VAT credit carry-forward in consistency check
Document expense bookkeeping workflow
```

Не `Добавлено...`, не `Added...`, не `adding...`.

### Перед PR

- [ ] Никаких персональных данных: NIF, ФИО, IBAN, clave de liquidación, expediente.
      В примерах — плейсхолдеры `[NIF]`, `[IBAN]`
- [ ] Числа в примерах либо сверены с *justificante*, либо помечены как непроверенные
- [ ] У новых файлов в `knowledge/` есть шапка `Актуально на:` и список того,
      что перепроверять
- [ ] Новый файл добавлен в карту базы знаний в [CLAUDE.md](CLAUDE.md) — иначе агент
      его не найдёт
